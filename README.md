# Learn Quant Trading with Phoebe: The Backtest That Lies

Sixteen 45-minute sessions on the one experiment that cannot be rerun. Six leader sessions on why
a backtest is one history rather than an experiment, how strategy search becomes a multiple-testing
problem, the leakage classes, and what a conventional data-science team carries over, must learn
and must unlearn. Ten practitioner sessions build the honest null, the best-of-N selection effect,
the deflated Sharpe ratio, purged and embargoed walk-forward splits, costs, survivorship and
lookahead, and sizing, ending in a bench that runs all of it in the browser.

Synthetic data only: seeded random walks with planted signal, no market series, no tickers, no
prices. Nothing here is investment advice.

- Open `index.html` in a browser; every page is static HTML with inline SVG.
- The engine is `assets/qt-live.js` (seeded, deterministic, self-testing on load). The Python
  reference `materials/qt_reference.py` agrees with it to 1e-6 on every canon number.

By Phoebe Fu.
